# Forwarding registration and repeated recovery

**Goal:** Prevent duplicate, missing and stale Emit/WatchProps notifications during multi-level forwarding, dynamic listener replacement, repeated errors and remounts, while keeping existing APIs.

**Contract:** A listener function registered repeatedly without removal remains one subscription. Removing and re-adding it creates a new registration, eligible from the next event; an old unsubscribe only removes its own registration. Existing mount guards, shallow references, same-owner queuing, cross-owner synchronous notification, and render commit timing remain unchanged.
