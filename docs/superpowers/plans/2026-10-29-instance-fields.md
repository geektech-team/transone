# 小程序与原生 App 的实例字段初始化

目标：沿用现有组件 API，正常构造对应的字段初始化先于 initState 和挂载钩子；支持编译器可表示的纯表达式，不执行业务模块来求值。

1. 共用字段序列和纯表达式求值。遍历真实业务继承链（父到子、声明顺序），跳过 static/declare，普通无初始化字段写入 undefined；同名覆盖不能提前消除祖先初始化。保留声明模块的常量作用域，拒绝副作用、访问未初始化字段的不支持运算、框架保留字段/方法覆盖和自定义 constructor。
2. 小程序在 Page.onLoad / Component.created 的用户钩子之前逐实例初始化字段和 state。生成器不能共享字段数组/对象，也不能永久折叠方法内对可变字段的访问。initState、静态样式和模板可解析受支持的字段引用；不支持的动态模板字段行为必须诊断。
3. 原生 App 使用同一字段规则，在每个选定组件实例上分别求值；initState、文本、内联样式、动作右值使用该实例的字段快照。保留原有 state/props 动态绑定；拒绝原生不能表示的字段写入、动态字段快照及非纯表达式，不扩展任意 JS 构造器或异步生命周期。
4. 验证使用 Web 作为字段顺序语义参考，小程序执行生成 JS（页面/组件及四种方言），App 检查三端原生 IR/产物和嵌套实例隔离；反例验证失败输出不覆盖旧产物。完成全仓 tsc、发布构建和完整 bun test。

重点：子类覆盖、无初始化覆盖与 declare、祖先字段读取当时值而 initState 读取最终字段、跨文件同名模块常量、对象/数组别名及实例隔离、早期 state/动态 props、不可表示的调用和写入、初始化钩子前的时序。
